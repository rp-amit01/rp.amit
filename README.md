# Amit Prajapati — DevOps & Cloud Engineer Portfolio

A responsive, modern portfolio website built with plain HTML, CSS and JavaScript.

## Features

- Responsive desktop / tablet / mobile layout
- Dark and light theme toggle
- Mobile hamburger navigation
- Scroll progress indicator
- Active navigation section
- Smooth scrolling
- Scroll reveal animations
- Hero section
- About section
- Skills and technology cloud
- Featured DevOps / Cloud projects
- Certifications and learning section
- Education / experience timeline
- Contact form UI
- Download CV button
- No framework required

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

Recommended:

```bash
# VS Code
Right click index.html
→ Open with Live Server
```

## Customize before publishing

1. Replace `Amit Prajapati` and the email with your real contact details if needed.
2. Replace GitHub / LinkedIn links with your profiles.
3. Put your actual PDF resume at:
   `assets/Amit-Prajapati-Resume.pdf`
4. Replace project `href="#"` links with your GitHub repositories or case-study pages.
5. Replace the `AP` avatar with your real profile photo if desired.
6. Connect the contact form to Formspree, EmailJS, a serverless function, or your own backend.

## Deployment

This static website can be deployed on:

- GitHub Pages
- AWS S3 + CloudFront
- Netlify
- Vercel
- Cloudflare Pages

For a DevOps portfolio, AWS S3 + CloudFront or GitHub Pages is a good project to showcase.
